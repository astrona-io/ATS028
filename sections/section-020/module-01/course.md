# Health Checks With Different Recovery Actions

This module develops health Checks With Different Recovery Actions. It connects the intended application behavior to declared resources and observed conditions.

## Learning Goals

- Distinguish startup, readiness and liveness actions.
- Choose a meaningful supported probe type.
- Evaluate thresholds and expected initialization time.
- Diagnose restarts separately from missing ready endpoints.

## Before You Start

Examples describe system behavior. No runtime is required. Read each field or diagnostic name as part of the stated contract.
