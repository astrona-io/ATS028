# API Discovery And Safe Definition Migration

This module develops aPI Discovery And Safe Definition Migration. It connects the intended application behavior to declared resources and observed conditions.

## Learning Goals

- Distinguish deprecation from endpoint removal.
- Discover served groups, versions and resources.
- Preserve behavior while changing a resource schema.
- Distinguish API support, validation and permission errors.

## Before You Start

Examples describe system behavior. No runtime is required. Read each field or diagnostic name as part of the stated contract.
