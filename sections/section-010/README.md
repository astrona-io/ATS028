# Understand API deprecations

This section covers understand API deprecations. You will study API Discovery And Safe Definition Migration. The lessons explain the responsible components, configuration relationships and failure cases relevant to application development.

Each module begins with its goals and ends with a summary. Reusable YAML knowledge checks follow the section summary and are registered separately for future presentation.

## Learning Outcomes

- Distinguish deprecation from endpoint removal.
- Discover served groups, versions and resources.
- Preserve behavior while changing a resource schema.
- Distinguish API support, validation and permission errors.
