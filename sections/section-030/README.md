# Use built-in CLI tools to monitor Kubernetes applications

This section covers use built-in CLI tools to monitor Kubernetes applications. You will study Built-In Inspection And Resource Metrics. The lessons explain the responsible components, configuration relationships and failure cases relevant to application development.

Each module begins with its goals and ends with a summary. Reusable YAML knowledge checks follow the section summary and are registered separately for future presentation.

## Learning Outcomes

- Identify cluster, namespace and identity context.
- Compare desired specification, status and events.
- Distinguish resource usage from declared allocation.
- Choose diagnostic commands for the observed lifecycle stage.

Each module pairs its concept readings with a guided practical sequence in an isolated playground. Finish the practice and closing summary before moving on. The YAML knowledge checks remain separate from the environment lifecycle.
