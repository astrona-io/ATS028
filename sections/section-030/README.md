# Use built-in CLI tools to monitor Kubernetes applications

This section covers use built-in CLI tools to monitor Kubernetes applications. You will study Built-In Inspection And Resource Metrics, Selecting And Shaping kubectl Output, Rollouts, Events And Watching Change. The lessons explain the responsible components, configuration relationships and failure cases relevant to application development.

Each module begins with its goals and ends with a summary. The section closes with a capstone lab and a knowledge check quiz.


You will select observations by the question they answer. Desired specification, current status, recent events and measured usage describe different facts. Their scope and timing must match the same workload and symptom before they support a diagnosis.

## Learning Outcomes

- Identify cluster, namespace and identity context.
- Compare desired specification, status and events.
- Distinguish resource usage from declared allocation.
- Choose diagnostic commands for the observed lifecycle stage.

Each module pairs its concept readings with a guided practical sequence in an isolated playground. Finish the practice and closing summary before moving on. The capstone combines the skills of every module in one task, and the quiz has 10 questions.

- Selecting And Shaping kubectl Output: Label And Field Selectors, Output Formats, Sorting And Resource Usage, Summary. Playground and 1 graded lab.
- Rollouts, Events And Watching Change: Rollouts, Revisions And Rollback, Events, Watching And Waiting, Summary. Playground and 1 graded lab.
- Capstone: Inspect A Fleet And Roll Back A Failed Update
