# Built-In Inspection And Resource Metrics

This module develops built-In Inspection And Resource Metrics. It connects the intended application behavior to declared resources and observed conditions.

## Learning Goals

- Identify cluster, namespace and identity context.
- Compare desired specification, status and events.
- Distinguish resource usage from declared allocation.
- Choose diagnostic commands for the observed lifecycle stage.

## Before You Start

Examples describe system behavior. No runtime is required. Read each field or diagnostic name as part of the stated contract.
